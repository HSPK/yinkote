# 00 · 产品概述

## 1. 定位

Yinkote 是一个**跨平台、本地优先、以浏览器为主界面**的文献管理系统。

形态上它不是"网站"，也不是传统"桌面软件"，而是：

```
用户安装 Yinkote  →  开机自启一个后台服务（含托盘图标）
                  →  浏览器打开 http://127.0.0.1:23130 即为完整工作台
                  →  Word 插件 / 浏览器扩展 / CLI / 第三方脚本 均调用同一 API
```

## 2. 目标用户

| 角色 | 关键诉求 |
| --- | --- |
| 研究生 / 科研人员 | 抓取文献、读 PDF 做标注、写论文时插入引文与参考文献 |
| 课题组 / 实验室 | 共享文献库、共享标注与笔记、统一引用样式 |
| 重度中文用户 | 知网/万方/维普/CNKI 抓取、GB/T 7714 引用样式、中文全文检索 |
| 极客 / 自托管用户 | 部署到 NAS、数据自主可控、API 可编程、可写脚本 |

## 3. 范围（Scope）

### 3.1 MVP 必须有

1. **条目管理**：多层级 collections（收藏夹）、条目 CRUD、标签、关联、回收站。
2. **元数据获取**：DOI / ISBN / PMID / arXiv 识别号查询；网页一键抓取；PDF 拖入自动识别元数据。
3. **导入导出**：BibTeX、RIS、CSL-JSON、EndNote XML、Zotero RDF；**从 Zotero 数据库一键迁移**。
4. **附件与阅读**：PDF/EPUB/网页快照存储（**自定义路径模板 + sidecar 元数据**）；内嵌 PDF 阅读器（高亮、下划线、笔记、区域截图、墨迹）。
5. **笔记**：富文本笔记（条目笔记 / 独立笔记），支持从标注生成笔记、`@` 引用条目、Markdown 粘贴。
6. **检索**：字段检索、标签筛选、保存的检索（saved search）、全文检索（含中文）。
7. **引文**：CSL 样式渲染，快速复制引文/参考文献；Word 插件插入与刷新引文域。
8. **插件通道**：浏览器扩展抓取入库；Word 加载项写作集成。

### 3.2 V1.x 规划

- **文献搜索 Agent**（[11](11-agents.md)）：自然语言 → 多源检索 / 深度调研 / 滚雪球 → 候选清单 → 一键入库
- **文献库问答 Agent**（[11](11-agents.md)）：范围内 grounded QA，答案带页码引用可跳转
- **智能文献库 + 论文项目库 + 收件箱**（[12](12-libraries-and-projects.md)）
- **文献关系图谱**（[13](13-knowledge-graph.md)）：引用网络、社区发现、知识盲区提示
- 群组库 / 多用户与权限（owner / editor / reader）
- 同步：自建同步节点、WebDAV、S3 兼容对象存储
- 其它 AI：摘要、关键词、自动标签、翻译、语义检索
- 移动端 PWA + 离线只读
- LibreOffice / WPS 插件、Obsidian / Logseq 集成

### 3.3 明确的非目标（Non-goals）

- ❌ 不做 SaaS 托管服务（首个大版本不做多租户云）
- ❌ 不做原生 iOS/Android App（用 PWA 覆盖）
- ❌ 不做通用云盘 / 文件同步（只同步文献库相关数据）
- ❌ 不追求与 Zotero **数据库文件级别**兼容（只做导入迁移与 API 层兼容）

## 4. 核心用户旅程

### 旅程 A：抓取一篇文献
```
浏览器打开 arXiv/知网页面 → 点击 Yinkote 扩展图标
  → 扩展抽取页面元数据（translator）+ 下载 PDF
  → POST http://127.0.0.1:23130/api/v1/connector/saveItems
  → 后台入库 → WebSocket 推送 → 已打开的 Web 工作台实时出现新条目
```

### 旅程 B：读 PDF 并做标注
```
工作台双击条目 → 内嵌阅读器（pdf.js）打开附件
  → 划词高亮 / 批注 → 增量 PATCH /annotations
  → 标注即时可被全文检索、可一键"从标注生成笔记"
```

### 旅程 C：写论文引用
```
Word 打开论文 → Yinkote 任务窗格 → 选择引用样式（如 GB/T 7714-2015）
  → 搜索条目 → 插入引文（写入 ContentControl + CustomXmlPart）
  → 文末"插入参考文献" → 后续任何改动点"刷新"重排全文
```

### 旅程 D：跨设备
```
台式机跑 Yinkote 服务 → 笔记本/平板浏览器访问 https://yinkote.内网域名
  → 同一份数据，无需同步；离线时用本地实例 + 同步节点合并
```

## 5. 成功指标

| 指标 | 目标 |
| --- | --- |
| 冷启动到 UI 可交互 | < 1.5s（10k 条目库） |
| 条目列表滚动 | 10 万条目 60fps（虚拟滚动） |
| 全文检索延迟 | p95 < 200ms（10 万文档） |
| 安装包体积 | < 40 MB（不含 pdfium 时 < 25 MB） |
| 常驻内存 | 空闲 < 120 MB |
| Zotero 库迁移成功率 | 条目字段 > 99%，附件 100% |
